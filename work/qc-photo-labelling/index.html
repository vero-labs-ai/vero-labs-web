A labelling tool that turns QC photos into training data

The same IT hardware refurbisher wants a camera to spot scratches, dents and cracks one day. That needs thousands of labelled photos first. We built a labelling screen inside the web app its QC staff already use, so labelling happens during normal checks.

    The problem
    
    
    
      
    Every device that comes in goes through quality checks by eye. The company wants a vision model to help grade devices, but a model is only as good as its examples, and it had none in a usable form.
    
      
    Generic labelling tools sit outside the company's systems, need separate logins and lose the link to the device record. Staff would not use them during a busy shift.
    
    
    
  
    

  
    
    
    What we built
    
    
    
      
      
        
    • Inside the existing app. A labelling screen added to the company's internal web app, next to the device record.
      • 
        
    • Tap and draw. Pick a defect, drag a box. It runs in the browser, so there is nothing to install.
      • 
        
    • Labels from the ERP. The defect list comes from the company's ERP, so the categories match how they already grade devices.
      • 
        
    • Clean output. Photos go to the company's own file server; each label is saved as structured data ready for model training.
      • 
      
    
    
    
  
    

  
    
    
    What we learned
    
    
    
      
      
        
    • Keep the original resolution. Box positions are stored in image pixels. If a photo is compressed or resized on the way, every box shifts. Photos now travel untouched.
      • 
        
    • Start at one checkpoint. Labelling begins at incoming QC, where the most devices pass, before spreading to other stages.
      • 
        
    • Labelling is a habit, not a project. It only works if it fits inside the check staff already do.
